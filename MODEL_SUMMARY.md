# Prediction Model Summary

This repository’s DVC pipeline trains a single machine-learning model that is then used for prediction.

## Model used for prediction

- **Algorithm:** `RandomForestClassifier`
- **Library:** `scikit-learn` (`sklearn.ensemble.RandomForestClassifier`)
- **Training script:** `dvc-pipeline/src/train.py`
- **Saved artifact format:** `joblib` (via `joblib.dump`)

## What the model predicts

- **Target column:** `Target`
- The model is trained as a **classification** model to predict the `Target` value from input features.

## Features used

From `dvc-pipeline/src/train.py`, the training features are explicitly:

- `Feature1`
- `Feature2`

These are selected with:

- `X = data[['Feature1', 'Feature2']]`

## Preprocessing that affects prediction

From `dvc-pipeline/src/preprocess.py`:

- `Feature1` is multiplied by **10** before training (and should be applied the same way before prediction):
  - `data['Feature1'] = data['Feature1'] * 10`

## Evaluation metric tracked

- **Metric:** Accuracy
- **Where written:** `metrics.txt`
- **Format:** `accuracy: <value>`
- Example currently in the repo (`dvc-pipeline/metrics.txt`):
  - `accuracy: 0.65`

## Artifacts produced by training

The training stage produces:

- A serialized model file (e.g., `models/model.joblib`)
- A metrics file (e.g., `metrics.txt`)

Both are generated by `dvc-pipeline/src/train.py`.
